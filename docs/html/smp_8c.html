Detailed Description

Implementierung des Symmetric Multiprocessing (SMP) Bootstrappings.

Enthält Funktionen zur Erkennung von CPU-Kernen via ACPI MADT, zum Starten der Application Processors (APs) mittels Trampoline-Code und zur Initialisierung des Pro-CPU-Schedulings.

Author
friedrichOsDev

static void smp_ap_main ( )
static

Einstiegspunkt im 64-Bit Long Mode für hochgefahrene Application Processors (APs).

Lädt GDT/IDT, initialisiert FPU/TSS/LAPIC, erstellt den Pro-CPU Idle-Thread sowie den Haupt-Kontext-Thread, schaltet Interrupts ein und geht in die Scheduler-Schleife über.

◆ smp_enable_lapic()

static void smp_enable_lapic ( )
static

Aktiviert und konfiguriert das Local APIC-Modul der aktuellen CPU.

Schaltet das Bit 11 in der IA32_APIC_BASE MSR ein, konfiguriert DFR, LDR, den Spurious Interrupt Vector Register (SIVR) sowie Task Priority (TPR).
