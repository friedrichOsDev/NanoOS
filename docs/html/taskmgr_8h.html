void ps_dump ( process_t *  proc_list)

Gibt eine strukturierte Übersicht der laufenden Prozesse, Threads und SMP-CPU-Zustände über COM1 aus.

Akquiriert die erforderlichen Spinlocks, um die Prozessliste sowie die Threads jedes Prozesses sicher zu durchlaufen. Gibt PID, Prozessname, TID, Threadname, Status und CPU-Affinität aus. Anschließend wird der Status aller bekannten CPU-Kerne (Online/Offline, aktiver Thread) aufgelistet.
