Detailed Description

Hauptheader der Multiboot2-Informationsstruktur.

Struktur zur Abbildung des MMIO-Registerblocks des HPET.

Repräsentiert die Register eines einzelnen HPET-Timers / Comparators.

Local x2APIC Struktur in der MADT (Typ 9).

Local APIC Address Override Struktur in der MADT (Typ 5).

Local APIC NMI Struktur in der MADT (Typ 4).

I/O APIC NMI Source Struktur in der MADT (Typ 3).

Interrupt Source Override Struktur in der MADT (Typ 2).

I/O APIC Struktur in der MADT (Typ 1).

Local APIC Struktur in der MADT (Typ 0).

Header für Unterstrukturen innerhalb der MADT.

Tag für die tatsächliche physische Ladeadresse des Kernels.

Tag für grundlegende Angaben zum konventionellen Speicher.

Tag für die neue ACPI v2.0+ Root System Description Pointer (RSDP) Struktur.

Tag für die alte ACPI v1.0 Root System Description Pointer (RSDP) Struktur.

Tag für die Grafik-Framebuffer-Konfiguration.

Layout der Bitfelder für Direct-Color/RGB-Framebuffer.

Farbinformationen für Paletten-Framebuffer.

Farbkomponenten-Eintrag für palettenbasierte Framebuffer.

Tag für die vollständige Memory Map des Systems.

Einzelner Eintrag in der Multiboot2-Memory-Map.

Tag für vom Bootloader mitgeladene Module (z. B. Initrd, Treiber).

Tag für den Namen/die Version des ausführenden Bootloaders.

Tag für die dem Kernel übergebene Kommandozeile.

Generischer Header für alle Multiboot2-Tags.

Der Pointer auf diese Struktur wird vom Bootloader im EBX-Register übergeben.
