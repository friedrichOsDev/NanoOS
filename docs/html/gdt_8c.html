uintptr_t  kernel_stack 
)
static

Initialisiert die TSS-Struktur für einen bestimmten Prozessorkern.

Verifiziert die 16-Byte-Ausrichtung der Stacks (RSP0 und IST1) für SSE/FPU-Kompatibilität, nullt die Struktur und setzt das Offset für die I/O-Bitmap auf die Größe des TSS (deaktiviert).

cpu_idDie ID des Prozessorkerns.
