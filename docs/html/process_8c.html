Detailed Description

Implementierung der Prozessverwaltung und -registrierung.

Bietet Funktionen zur Erstellung von Prozessen, Vergabe von eindeutigen Thread-sicheren PIDs und Anfügen von Prozessen an die globale Prozessliste.
