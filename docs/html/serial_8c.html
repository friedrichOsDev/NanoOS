Detailed Description

Implementierung des UART 16550 Serial-Driver.

Enthält Low-Level-Funktionen zur Port-Ansteuerung, Pufferverwaltung und synchronisierten formatierte Log-Ausgaben.

◆ serial_init()

void serial_init ( uint16_t  port)

Initialisiert einen UART COM-Port für serielle Übertragung.

Konfiguriert die Baudrate (115200 Baud), Deaktiviert Interrupts und setzt die Datenleitungen auf 8N1 (8 Datenbits, keine Parität, 1 Stoppbit).

Parameters
portI/O-Port-Adresse des COM-Ports (z. B. COM1/0x3F8).
