Detailed Description

Schnittstelle für den Round-Robin-Kernel-Scheduler.

Bietet Funktionen zur Verwaltung der Thread-Warteschlangen, Zeitsteuerung (Ticks), Zuweisung von CPU-Affinitäten und Kontextwechseln im Präemptiv-Betrieb.
