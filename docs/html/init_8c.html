Detailed Description

Hauptinitialisierungsroutine und Multiboot2-Parser des Kernels.

Richtet die grundlegenden Architektur-Komponenten (GDT, IDT, PMM, VMM, Heap, ACPI, APIC, HPET, RTC), das Multi-Core-Scheduling und die ersten Init-Threads ein.
