void pmm_init ( )

Initialisiert den physischen Speicherverwalter.

Parst die Memory Map vom Bootloader, baut die Bitmap auf und sperrt reservierte Bereiche wie Kernel, Bitmap, Framebuffer und den Speicher unter 1 MiB.

phys_addr_t pmm_page_alloc ( )

Allokiert eine freie physische 4-KiB-Seite.

Sucht über Bitmuster-Scans (QWORD) nach einer freien Seite und markiert diese als belegt.

Returns
Physische Startadresse der allokierten Seite oder 0 im Fehlerfall/Speichermangel.
