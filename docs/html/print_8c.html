Interne Kernfunktion zur Verarbeitung und Formatierung von Zeichenketten.

Unterstützt sowohl schmale (8-Bit char) als auch breite (32-Bit uint32_t) Strings und verarbeitet gängige Format-Spezifizierer (d, i, u, x, X, o, f, s, c, p, %%).

Parameters
destZeiger auf den Zielpuffer (char* oder uint32_t*).
sizeMaximale Puffergröße.
formatFormatstring (const char* oder const uint32_t*).
argsListe der variablen Argumente.
is_widetrue für 32-Bit-Zeichen (UTF-32), false für standardmäßige 8-Bit-Zeichen.
Returns
Gesamtanzahl der verarbeiteten/generierten Zeichen.
