void gdt_flush ( uint64_t  gdt_ptr_phys)
extern

Lädt die Global Descriptor Table (GDT) und aktualisiert die Segmentregister.

Führt den Assembler-Befehl lgdt aus, um den GDTR-Zeiger zu laden, aktualisiert das CS-Register via Far-Return (retfq) auf das Kernel-Code-Segment (0x08) und lädt die Daten-Segmentregister (DS, ES, FS, GS, SS) neu mit 0x10.
