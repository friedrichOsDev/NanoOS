Detailed Description

Symmetric Multiprocessing (SMP) – Schnittstelle und Kernstrukturen.

Verwaltet Mehrkern-CPUs, pro-Prozessor-Strukturen (Per-CPU-Data) und bietet Hilfsfunktionen zur Bestimmung des aktuellen CPU-Cores.
