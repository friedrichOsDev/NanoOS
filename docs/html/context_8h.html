Führt einen Kontextwechsel zwischen zwei Threads durch.

Speichert den aktuellen Registerzustand (callee-saved Register RBP, RBX, R12–R15) sowie optional den FPU/SSE-Zustand des vorherigen Threads auf dessen Stack. Wechselt anschließend auf den Stack des nächsten Threads und stellt dessen Register- und FPU/SSE-Zustand wieder her.

Parameters
prev_rsp_ptrZeiger auf das RSP-Feld des vorherigen Threads (&prev->rsp), in dem der aktuelle Stack-Pointer gespeichert wird.
next_rspDer gespeicherte Stack-Pointer (next->rsp) des Ziel-Threads.
prev_fpu_stateZeiger auf den Speicherbereich für den FPU/SSE-Zustand des vorherigen Threads (kann NULL sein).
next_fpu_stateZeiger auf den Speicherbereich für den FPU/SSE-Zustand des nächsten Threads (kann NULL sein).

void thread_entry_stub ( )

Einstiegspunkt (Stub) für neu erstellte Threads.

Wird beim ersten Kontextwechsel in einen neu erstellten Thread angesprungen. Gibt den anfänglichen Scheduler-Lock frei, aktiviert die Interrupts (sti), ruft die Thread-Funktion mit dem vorgegebenen Argument auf und beendet den Thread anschließend ordnungsgemäß über thread_exit().

Note
Erwartet die Thread-Funktion in Register R12 und das Argument (void *arg) in Register R13.
